# موقع الذكرى السنوية للزواج | رشا وهاني ❤️

موقع بسيط، دافئ ورومانسي مصمم خصيصاً كمفاجأة حميمية من **رشا** إلى زوجها الحبيب **هاني** بمناسبة ذكرى زواجهما (28 يوليو 2003).

## 🌟 مميزات الموقع

- **تجربة صفحة واحدة انسيابية**: تصميم دافئ وسريع التركيز بدون تعقيدات أو أشرطة تنقل جانبية.
- **كلمة السر الحصرية**: `2872003` لفتح المفاجأة.
- **الواجهة الرئيسية (Hero)**: صورة سينمائية دافئة مع رسالة الحب الأولى.
- **رسالة حب وجدانية**: مكتوبة بلغة عربية مصرية طبيعية بعيدة عن الرسمية والتكلف.
- **معرض الصور البسيط**: عرض شبكي أنيق مع تأثيرات التكبير الناعمة.
- **عداد الحب الحي**: حساب حي ومستمر بالسنوات، الأشهر، الأيام، الساعات، الدقائق، والثواني منذ 28 يوليو 2003.
- **زر المفاجأة الختامي**: إطلاق للألعاب النارية والـ Confetti والقلوب السابحة مع الرسالة الختامية الأبدية.
