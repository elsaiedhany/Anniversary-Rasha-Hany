# موقع الذكرى السنوية للزواج | رشا وهاني ❤️

موقع فاخر وسينمائي مصمم خصيصاً كمفاجأة من **رشا** إلى زوجها **هاني** بمناسبة ذكرى زواجهما العطرة (28 يوليو 2003).

## 🌟 المميزات الفنية والتصميمية

- **نظام تصميم فاخر**: أسود ملكي (`#0A0A0A`)، ذهبي (`#D4AF37`)، وأبيض ناصع مع تأثيرات Glassmorphism والإضاءة الخافتة.
- **لغة الموقع**: اللغة العربية المصرية الطبيعية والأنيقة.
- **شاشة القفل والحماية**: كلمة المرور (`28072003`) مع اهتزاز أنيق عند الخطأ وانتقال سينمائي سلس عند الفتح.
- **مقدمة سينمائية**: كتابة متحركة بـ Typed.js للعبارة الشهيرة "كل سنة وإنت حبيبي ❤️".
- **عداد الزواج المباشر**: حساب حي بالسنوات، الأشهر، الأيام، الساعات، الدقائق والثواني منذ 28 يوليو 2003.
- **شريط زمن الحب**: عرض رحلة الحب والوفاء عبر السنوات بطريقة عاطفية راقية.
- **رسالة الحب الكبرى**: خطابات وجدانية تعبر عن الحب والامتنان والأمان والعشرة الطيبة.
- **معرض الصور الفاخر**: شبكة تصاميم متجاوبة مع معاينة Lightbox كاملة والتحكم بلوحة المفاتيح.
- **مشغل الموسيقى الرومانسي**: عزف رومانسي خاص مبني بـ Web Audio API ومؤشرات equalizer تفاعلية.
- **المفاجأة الكبرى والألعاب النارية**: احتفال كامل بـ Confetti وFireworks ألعاب نارية مع رسالة الختام السينمائية.
- **مؤثرات متقدمة**: خيوط وجسيمات ذهبية سابحة، قلوب عائمة، تتبع إضاءة الماوس، وشريط تقدم التمرير.

## 🛠️ التقنيات المستخدمة

- **HTML5 Semantic & SEO Meta Tags**
- **Vanilla CSS3** (Custom Properties, Glassmorphism, Animations, Flexbox/Grid, Responsive Media Queries)
- **Vanilla JavaScript (ES6+)**
- **GSAP & AOS** (أنيميشن التمرير والظهور السينمائي)
- **Typed.js** (الكتابة التفاعلية)
- **Canvas Confetti** (المفاجآت والاحتفال)

## 🚀 طريقة التشغيل

افتح ملف `index.html` في أي متصفح حديث، واستمتع بتجربة سينمائية فريدة من نوعها.
